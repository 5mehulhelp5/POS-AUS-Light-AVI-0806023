AL POS - desktop app
====================

Install (once on each computer):
  1. Double-click "Install AL POS.bat".
     If Windows says "Windows protected your PC", click "More info" then "Run anyway".
  2. Answer Y if the POS should open automatically when the computer starts, otherwise N.
  3. An "AL POS" icon appears on the desktop and in the Start menu.
     Right-click it and choose "Pin to taskbar" to keep it on the taskbar.

The POS opens in its own window (no tabs or address bar) using this computer's
Chrome (or Edge if Chrome isn't installed), so the POS login and printer settings
are the same as before. Updates to the POS appear automatically - nothing to reinstall.

Remove: double-click "Uninstall AL POS.bat".
